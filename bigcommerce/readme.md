Status ID	Status Name	Definition / Trigger
0	Incomplete	An order was started but payment was abandoned.
1	Pending	Customer started checkout but didn't complete it.
2	Shipped	Items have been shipped.
3	Partially Shipped	Only some items in the order have shipped.
4	Refunded	Entire order amount was refunded to the customer.
5	Cancelled	Order was cancelled.
6	Declined	Payment gateway or merchant declined the order.
7	Awaiting Payment	Order is placed, but payment is unconfirmed.
8	Awaiting Pickup	Order is ready for local pickup.
9	Awaiting Shipment	Order is paid and ready to be packaged/shipped.
10	Completed	Client received the items (often used for digital downloads).
11	Awaiting Fulfillment	Payment is verified, items need to be pulled from stock.
12	Manual Verification	Order requires a security or manual fraud review.
13	Disputed	Customer initiated a PayPal dispute or chargeback.
14	Partially Refunded	Only a portion of the order amount was refunded.
